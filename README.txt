配信スタートランチャー
======================

配信で使うアプリをまとめて起動・終了するツールです。
アプリは自由に追加でき、起動後に押したいボタン(例: CastCraft の「Screen」→
確認ダイアログの「起動する」)を自動でクリックできます。

■ 使い方
1. StreamLauncher.exe をダブルクリック
   ※ 初回に「WindowsによってPCが保護されました」と出たら
     「詳細情報」→「実行」を押してください。
2. 初回は OBS / CastCraft / VSeeFace を自動で探してリストに入れます。
   見つからなかったアプリはチェックが外れています。
3. 「起動」を押すと、チェックの入ったアプリを上から順に起動します。
   設定は %APPDATA%\StreamLauncher\settings.json に保存されます。

■ 起動リスト
- 追加 ▼ … 「アプリを選んで追加…」で好きな exe を追加できます。
             OBS / CastCraft / VSeeFace / CommentDeck / LiveAnnouncer は
             プリセットから追加できます(CommentDeck は OBS より前に入ります)。
- 削除 / ↑ 上へ / ↓ 下へ … 選択中のアプリを削除・並べ替え
- チェックを外したアプリは起動しません(リストには残ります)

■ アプリの設定(リストで選んだアプリ)
- 場所           : exe か、インストールしたフォルダ
                   (フォルダの場合は「exe ファイル名」を中から探します)
- 起動引数       : アプリに渡すオプション
- 起動後の待機   : 次のアプリを起動するまで待つ秒数
- 起動後に押すボタン : 1行に1つ、上から順にクリックします
                   (ボタン名は、アプリを起動した状態で「UI要素一覧」を押すと確認できます)
- 関連プロセス名 : ボタンで立ち上がるアプリ(例: CastCraftScreen)。
                   起動の確認と、全部終了で一緒に閉じるのに使います。
- マウスでクリックする   : ボタンが押されないときに試してください
- 全部終了で閉じる       : 「全部終了」の対象にするか
- 強制終了の前に確認する : OBS など、強制終了すると困るアプリ向け

■ 全部終了
  確認のあと、起動したのと逆の順番で終了します。
  通常の終了で閉じないアプリは強制終了します
  (「強制終了の前に確認する」がオンのアプリは確認してから)。
  「全部終了したらランチャーも閉じる」がオンなら、最後にランチャーも閉じます
  (閉じられなかったアプリがあるときは、ログを確認できるよう開いたままにします)。

■ 名前で押せないボタン(VSeeFace の「スタート」など)
  Unity 製のアプリなどは、ボタン名を外から読み取れません(「UI要素一覧」に出てきません)。
  その場合は位置で押します。
  1. そのアプリを起動して、押したいボタンが見える状態にする
  2. リストでアプリを選び「位置を記録…」→ OK
  3. 3秒以内に押したいボタンの上にマウスを置く
  → 「起動後に押すボタン」に [位置1] が追加されます。
  起動時は、記録したボタンの画像が画面に出るまで待ってからクリックします
  (位置はウィンドウに対する割合で覚えるので、ウィンドウを動かしても大丈夫です)。

■ ボタンが押されないとき
- 一度そのアプリを終了してから「起動」を押してください。
- Electron 製のアプリ(CastCraft など)は、起動引数に
  --force-renderer-accessibility が無いとボタンを読み取れません。
- 「UI要素一覧」で表示される名前と、「起動後に押すボタン」が一致しているか確認してください。

■ 配信モニター(配信の健康状態を見張る)
  「配信モニター」ボタンで開きます(起動が終わったときに自動で開くこともできます)。
  OBS の WebSocket 機能を使って、次のような問題を見つけると音と通知で知らせます。
    ・回線が不安定(直近 30 秒で 1% 以上のフレームが送れていない)/ 混雑 / 再接続中
    ・ビットレートが OBS の設定値の 70% を下回った
    ・エンコード・描画の遅れが出始めた(PC の負荷が高い)
    ・マイクがミュート / 配信中に 30 秒以上無音 / 音割れ(ピーク -1dB 超え)
    ・必ず有効にしておくフィルター(ボイスチェンジャーなど)が無効
    ・リプレイバッファが止まっている(使う場合のみ)
    ・OBS の CPU 使用率が 10 秒以上高い / 録画先の空きが少ない
    ・配信中に OBS が落ちた
  「事前チェック」では、配信を始める前にストリームキー・現在のシーン・FPS・
  空き容量・マイク(話しかけて音が入るか)をまとめて確認できます。

  準備(最初の 1 回だけ):
    OBS の「ツール → WebSocket サーバー設定」で
    「WebSocket サーバーを有効にする」にチェックを入れてください。
    同じ PC の OBS なら、パスワードは自動で読み込みます。
  「設定」で、警告する条件(ドロップ率・ビットレートなど)、見張るマイク、
  必ず有効にしておくフィルター(1 行に「ソース名:フィルター名」)、
  配信先の接続方法(ストリームキー / アカウント接続)、
  Discord への通知(Webhook URL)を変えられます。

■ Stream Deck / VSD Craft のボタンに登録する
  1. 「スタートメニューに登録」を押す
     → スタートメニューに次の3つが追加されます
        StreamLauncher           … 画面を開く
        StreamLauncher 配信開始  … 起動リストをまとめて起動
        StreamLauncher 全部終了  … まとめて終了
  2. VSD Craft / Stream Deck の「開く(アプリを起動)」アクションで、
     アプリ一覧から上のどれかを選んでボタンに割り当てる
  - ランチャーがすでに開いている場合は、開いているランチャーがそのまま動きます。
  - ボタンから確認なしで終了したい場合は「全部終了の前に確認する」を外してください。
  - コマンドラインからも使えます:StreamLauncher.exe --start / --closeall

■ アップデート
  起動時に新しいバージョンがあるか自動で確認します。
  あればボタンが「vX.Y.Z に更新」に変わるので、押すと自動で更新・再起動します。
  (更新ファイルは署名を検証してから適用します)
  Program Files など書き込めない場所に置いている場合は自動更新できないので、
  デスクトップなどに置いてください。

■ その他
- 「このランチャーを開いたらすぐに起動を始める」にチェックを入れると、
  exe を開くだけで最後まで自動で進みます。
- OBS がクラッシュ後に「セーフモードで起動しますか」と聞いてくる場合は、
  OBS の起動引数に --disable-shutdown-check を入れると表示されなくなります。
- 設定をリセットしたいときは %APPDATA%\StreamLauncher フォルダを削除してください。
- 動作環境: Windows 10 / 11(追加のインストールは不要です)
